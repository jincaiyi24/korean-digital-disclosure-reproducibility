# KLUE-BERT·KR-FinBERT 고정 300문장 비교 재현

이 자료는 논문 3.3절과 부록 A3의 신경모형 비교를 재현한다. 2026년 10월 25일 완료한 두 모형 × 네 시드의 실제 학습·예측을 보존하고, 같은 300개 인간 참조 라벨에 대한 비가중·설계가중 평가를 다시 계산한다. 기존 규칙분류·회귀 진입점과 별도로 실행하며 논문 원고와 회귀자료는 변경하지 않는다.

## 1. 파일 구성과 고정 표본

세 폴더만 사용한다. `코드`는 실행·평가 연산과 의존성, `CSV자료`는 고정 입력·예측·지표, `설명서`는 설정·출처·실행기록을 담는다. 모두 `벤치마크_` 접두어로 구분한다.

`벤치마크_학습.csv` 1,500문장, `벤치마크_개발.csv` 300문장, `벤치마크_시험.csv` 300문장을 그대로 사용한다. 원래 테스트의 N001–N300 순서, 기업·연도·접수번호와 문장 본문을 보존하였다. 학습·개발·시험의 기업 수는 717·158·248개이며 기업과 NFKC/공백제거 문장 해시의 교집합은 0이다. 이전 2,700문장 비교의 정규화 문장도 새 학습·개발에서 제외하였다. 고정분할목록과 파일 SHA-256으로 동일한 표본을 확인한다. 이 고정 비교에는 역사적 문장 후보풀 전체를 다시 추출할 필요가 없다.

학습·개발 라벨은 수정하지 않은 Python 규칙기의 출력이다. 시험 CSV의 `label` 역시 규칙 라벨이며 `human_label`은 비어 있다. 인간 평가에는 별도 `벤치마크_인간참조.csv`의 최종 라벨을 sample_id·문장 SHA-256·기업·연도·보고서 번호로 연결한다. 최종 인간 범주는 BMODD 75, NonBMODD 86, Exclude 139문장이다. 최초 코더 A/B 판정과 22개 불일치의 최종 판정을 모두 유지한다. 인간 시험 라벨을 학습·개발·모형 선택에 사용하지 않았다.

실제 입력은 `기업명: {corp_name}\n보고연도: {year}\n문장: {sentence}`이다. 기업명을 익명 문자열로 바꾸거나 문장을 재번역하지 않는다. 원문·모형 입력의 두 해시를 각각 확인한다. 회사명은 공개 기업 정보이며 코더의 개인 신원·이메일·로컬 Excel 경로는 포함하지 않는다.

## 2. 사전학습 모형과 학습 설정

| 모형 | 공식 저장소 | 고정 revision |
|---|---|---|
| KLUE-BERT | [klue/bert-base](https://huggingface.co/klue/bert-base/tree/77c8b3d707df785034b4e50f2da5d37be5f0f546) | `77c8b3d707df785034b4e50f2da5d37be5f0f546` |
| KR-FinBERT | [snunlp/KR-FinBert](https://huggingface.co/snunlp/KR-FinBert/tree/9ccc6ae2a35c65ed7156da9dc1fc5311f69abc3e) | `9ccc6ae2a35c65ed7156da9dc1fc5311f69abc3e` |

각 모형의 원래 tokenizer를 사용한다. KR-FinBERT는 고정 revision의 `pytorch_model.bin`을 `weights_only=True`로 읽어 safetensors로 변환한 파일을 사용했다. 변환 뒤 205개 텐서의 키·형상·dtype·값이 모두 같은지 검사한다. 공개 변환 절차는 safetensors 메타데이터의 직렬화 순서도 고정하여 원래 학습 입력 파일의 SHA-256을 확인한다. 원래 bin 및 변환 파일 해시는 고정설정에 있다. 가중치 자체는 이 저장소에 올리지 않으며 공식 제공처에서 확보한다.

시드는 20261022, 20261023, 20261024, 20261025이다. 각 시드에서 두 모형의 pooler와 세 범주 분류 head를 같은 초기 상태로 새로 만들고 사전학습 encoder의 나머지 텐서는 유지한다. 세 범주는 BMODD=0, NonBMODD=1, Exclude=2이다. 3에포크, 최대 192토큰, 배치 8, 누적 2, AdamW, 학습률 2e-5, weight decay 0.01, warmup 0.1, gradient norm 1.0을 사용한다. 클래스 가중치·혼합정밀도·TF32는 사용하지 않고 결정적 연산을 설정한다. 각 시드에서 개발 Macro F1이 가장 높은 에포크를 선택하며 동점이면 앞선 에포크를 유지한다. 고정 시험은 선택 이후 한 번 평가한다.

원본 학습 연산 파일은 실행 당시와 바이트가 같고 공개 진입점은 경로·입출력 연결만 담당한다. 원본 함수의 역사적 900개 시험 요청은 명시적 어댑터로 이번 실제 300개를 전달한다. 예전 900문장 실험을 이번 인간 300문장 비교로 혼합하지 않는다. 각 시드의 3개 개발 예측, 최종 시험 예측과 클래스 확률, 학습 로그, 실제 선택된 에포크와 모델 해시를 함께 보존한다.

## 3. 저장된 예측으로 먼저 확인하기

명령은 저장소의 `BMODD_재현자료` 폴더에서 실행한다. 아래 Windows 예시는 별도의 Python 3.12 환경을 사용한다. 규칙·회귀 재현용 Python 3.13 환경과 구분한다.

```powershell
Set-Location .\BMODD_재현자료
py -3.12 -m venv ..\.benchmark-venv
$benchPy = "..\.benchmark-venv\Scripts\python.exe"
& $benchPy -m pip install -r .\코드\벤치마크_평가의존성.txt
& $benchPy -B .\코드\벤치마크_실행.py verify
& $benchPy -B .\코드\벤치마크_실행.py evaluate --out ..\benchmark_eval_01
```

평가에는 GPU나 모델 다운로드가 필요 없다. 파일 해시, 고정 분할과 기업·문장 격리, 인간 참조 연결, 네 층의 각 75개 표본과 N_h/75 가중치, 8개 시험 예측의 ID·확률·argmax 및 개발표본 선택을 검사한다. 예측을 새로 만들어 저장된 결과를 덮어쓰지 않는다. 출력 경로는 존재하지 않는 새 폴더로 지정한다.

동일한 최종 인간 라벨에 대해 Accuracy, 세 범주의 Precision·Recall·F1, Macro F1과 혼동행렬을 비가중·설계가중으로 계산한다. 네 시드 지표의 산술평균을 보고하며 예측을 앙상블로 합치지 않는다. 신뢰구간은 네 시드를 고정한 채 각 원래 층에서 75개씩 같은 인덱스로 재표집한 5,000회 부트스트랩(시드 20261025)이다. 세 방법의 구간, 개별 시드 구간과 규칙법 대비 대응 Macro F1 차이를 함께 산출한다. 설계가중 범위는 검증을 위해 사후 구축한 중복제거 문장표본틀이다.

| 집계 | 방법 | Accuracy | Macro F1 |
|---|---|---:|---:|
| 비가중 | Python 규칙 | 0.9100 | 0.9041 |
| 비가중 | KLUE-BERT | 0.6825 | 0.6657 |
| 비가중 | KR-FinBERT | 0.7092 | 0.6959 |
| 설계가중 | Python 규칙 | 0.8809 | 0.3901 |
| 설계가중 | KLUE-BERT | 0.8026 | 0.5037 |
| 설계가중 | KR-FinBERT | 0.8254 | 0.5888 |

비가중 값은 같은 수를 뽑은 300문장 표본에 대한 비교이고 설계가중 값은 원래 층 크기를 반영한 비교이다. 공개 스크립트는 두 결과를 모두 재계산한다. 원래 학습 기록의 `test_metrics`는 규칙 라벨에 대한 일치도이므로 인간 정확도와 구분한다.

## 4. 두 모형을 새로 학습하기

실제 학습은 Python 3.12.14, PyTorch 2.7.1+cu126, transformers 4.57.1, tokenizers 0.22.1, safetensors 0.6.2, NumPy 2.2.6, huggingface-hub 0.36.2를 검사한다. 원래 장비는 NVIDIA GeForce RTX 3060 Laptop GPU이다. 학습 당시 드라이버 버전은 기록되지 않았다. 10월 22일 전체 환경 기록과 10월 25일 학습 전에 강제 확인한 핵심 버전을 구분해 제공한다.

```powershell
& $benchPy -m pip install -r .\코드\벤치마크_학습의존성.txt
& $benchPy -m pip check
& $benchPy -B .\코드\벤치마크_실행.py download-models --models ..\benchmark_pretrained
& $benchPy -B .\코드\벤치마크_실행.py train --models ..\benchmark_pretrained --out ..\benchmark_train_01
& $benchPy -B .\코드\벤치마크_실행.py evaluate --runs ..\benchmark_train_01 --out ..\benchmark_eval_retrained_01
```

`download-models`만 고정 공식 모형을 받는다. `train`은 이후 네트워크를 끄고 고정된 자료와 모델 파일로 8개 학습을 실행한다. 학습에서는 인간 참조 라벨을 파싱하지 않는다. `evaluate --runs`는 새 학습의 완료 기록·고정 입력·각 시드의 개발 선택과 시험 예측을 검증한 뒤 같은 인간 참조로 평가한다. 이때 원래 결과와의 차이도 별도 CSV에 남기며 새 결과를 원래 값으로 바꾸지 않는다. 저장된 예측에 대한 지표는 같은 값으로 재계산할 수 있으며, 새 GPU 학습의 비트 단위 동일성은 장비·드라이버·연산환경까지 같은지와 구분해서 확인한다.

## 5. 자료 출처와 권리

고정 CSV는 사업보고서에서 추출한 연구용 문장과 출처·라벨·해시를 제공하며 전체 사업보고서나 모델 가중치를 포함하지 않는다. 접수번호로 [DART](https://dart.fss.or.kr/) 원문을 확인할 수 있다. 문장과 모형에는 원제공자의 권리가 적용되고 저장소의 MIT는 작성한 소프트웨어에 적용된다. KLUE 고정 모델카드는 CC-BY-SA-4.0을 표시한다. KR-FinBERT 고정 모델카드에는 명시적 라이선스가 확인되지 않아 원 제공처 조건을 확인하여 확보한다.

이 모듈은 2026년 10월 26일에 추가한 신경모형 비교 보충자료다. 기존 주분석 안내서의 BERT·FinBERT 제외 표기는 당시 규칙·회귀 실행 범위에 관한 기록이며, 여기의 별도 비교 모듈과 원래 실행 결과를 구분한다.
